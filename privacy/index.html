Privacy

gbps.run does not use advertising, tracking cookies or user accounts.

  • Test traffic: the test downloads and uploads random bytes to Cloudflare's speed-test endpoints (speed.cloudflare.com); if those are unreachable, a public CDN file is used for the download portion. Those services see your IP address as part of serving that traffic, as any website does.
  • Connection info: your IP, network name and nearest server are fetched from Cloudflare to display on the page. They're shown to you only and not stored by gbps.run.
  • History: your past results are saved in your browser's local storage on your device. Clear them any time with the Clear history button.
  • Shared result links: contain only the numbers you choose to share, in the link itself. Nothing is stored on a server.
  • Analytics: if enabled, the site uses privacy-friendly, cookie-free page-view counting only.
