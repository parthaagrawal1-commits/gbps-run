    Test data is served by Cloudflare's global network (speed.cloudflare.com), so the server is usually within a few hundred miles of you. Nothing about your test is uploaded anywhere except the random test bytes themselves.

    Questions about this test

    What speeds should Cox deliver?

    Cox tiers typically run from about 100 Mbps to 2 Gbps download, with uploads of roughly 5–100 Mbps depending on tier and market. Wired tests at 85–95% of plan are normal.

    Why is Cox upload so low?

    Cable upload capacity is limited by design. If you need more, check whether an upgraded tier or fibre is available.

    Is this affiliated with Cox?

    No. gbps.run is independent and ad-free.
