# gbps.run — free internet speed test

Live at **https://gbps.run** · Live monitor: **https://gbps.live**

Download, upload, ping, jitter, packet loss and **bufferbloat (ping under load, graded A+–F)**, then plain-language verdicts for 4K streaming, video calls, gaming, working from home and more. Detects iCloud Private Relay / VPNs. No ads, no accounts, results stay on your device. English, Español, Português, हिन्दी.

Embed it anywhere:
```html
<iframe src="https://gbps.run/embed/" width="100%" height="560" style="border:0;border-radius:16px" loading="lazy" title="gbps.run speed test"></iframe>
```

Source for the generator is in `_src/` (see `_src/DEPLOY.md`). The repo root is the built site.
